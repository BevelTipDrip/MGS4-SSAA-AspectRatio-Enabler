# MGS4-SSAA-AspectRatio-Enabler
This Mod Enables Supersampling, Aspect ratio changes, HUD scaling/placement (no stretching on 4:3, 21:9, or (16:10 comming soon), Recticle scaling fix for horizontal render resolutions above 4095, Pillar/Letter boxing for non 16:9 aspect ratios, and normalized cutscene FOV to maintain framing.
